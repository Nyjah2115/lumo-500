# Lumo — „strona za 500 zł” (do rolki 500 vs 3000)

To samo mieszkanie 70 m² i te same grafiki co w Lumo (https://nyjah2115.github.io/lumo/), ułożone jak tani szablon
biura nieruchomości: zielono-złoty, wyszukiwarka ofert, galeria ze strzałkami, tabelka „Szczegóły oferty”,
opis WIELKIMI LITERAMI, „Zapytaj o cenę”, niedziałająca mapa, baner cookies. Bez nazwy biura, bez lokalizacji
i bez ceny (dane przykładowe, koncept).

Otwórz w Chrome/Safari na pełnym ekranie. Skróty: **A** auto-scroll (~16 s), **C** kursor, **0** góra,
**P** okienko „oddzwonimy”, **K** baner cookies, **G** następne zdjęcie w galerii.
